# Diabetes Prediction

Machine learning project to predict diabetes using Python and Scikit-learn.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Model Training using Logistic Regression
4. Model Saving and Prediction

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Model Training using Logistic Regression
5. Model Evaluation
6. Saving the model for prediction

## Files in the Repository

- `LogisticRegression.ipynb` → Model training notebook  
- `App.py` → Python script for prediction  
- `DiabetesPrediction.pkl` → Trained model file  
- `diabetes.csv` → Dataset  
- `requirements.txt` → Required Python libraries
