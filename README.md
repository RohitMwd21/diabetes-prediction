# Diabetes Prediction using Machine Learning

This project predicts whether a person is likely to have diabetes based on medical attributes using a machine learning model.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Dataset

The dataset used is the **Pima Indians Diabetes Dataset**, which contains medical data such as:

- Glucose Level
- Blood Pressure
- BMI
- Insulin
- Age

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Model Training using Logistic Regression
5. Model Evaluation
6. Saving the model for prediction

## Files in the Repository

- `LogisticRegression.ipynb` → Model training notebook  
- `App.py` → Python script for prediction  
- `DiabetesPrediction.pkl` → Trained model file  
- `diabetes.csv` → Dataset  
- `requirements.txt` → Required Python libraries
